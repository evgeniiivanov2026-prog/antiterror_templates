# Контур

Расширение Chrome. При наведении на ссылку показывает карточку: похоже на достоверный материал, неоднозначно, похоже на фейк или сатира.

Оценка не является фактчеком. Это набор сигналов и, если модель доступна, осторожная поправка к ним.

## Установка

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. «Загрузить распакованное» и выберите эту папку `kontur`.
4. Откройте `demo/feed.html` через локальный сервер или любую новостную страницу и наведите курсор на заголовок.

Пункт меню вроде «Главная» карточку не вызывает. Любую ссылку можно проверить через Alt + наведение.

## Как считается оценка

Сначала, на устройстве и без запроса к модели:

- каталог редакций, агентств, сатиры и доменов, которые уже светились как фабрики вымышленных новостей;
- язык заголовка: кликбейт, капс, псевдомедицина, конспирологическая рамка;
- форма адреса: сокращатель, punycode, голый IP, зона-однодневка;
- если страница открылась — автор, дата, совпадение текста ссылки и заголовка.

Неизвестный домен сам по себе не означает фейк. Государственный источник не ставится в один ряд с выдуманной газетой: у него другая подпись.

Дальше, если включено:

- **Авто** — Gemini Nano в Chrome (Prompt API, Chrome 138+). Текст не уходит с устройства. Модель нужно один раз скачать из попапа расширения.
- **Облако** — ключ Gemini в настройках. В запрос уходят адрес, заголовок и короткий фрагмент. Ключ лежит только в `chrome.storage.local`.
- **Только сигналы** — модель не вызывается.

Если модель спорит с сильными сигналами, её влияние ограничено. Сатира остаётся сатирой. Спокойный материал Reuters модель не может одной фразой превратить в фейк.

## Демо карточки

`demo/preview.html` показывает те же состояния, что и движок, без установки расширения. Шрифты Manrope, Unbounded и JetBrains Mono лежат в `assets/fonts` и распространяются по SIL OFL (тексты лицензий рядом).
