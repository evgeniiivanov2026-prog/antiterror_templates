# Aegis

Профессиональный журнальный шаблон антитеррора для **WordPress 6.7+**.

Тема собрана из двух исходников репозитория:

- **JournalX** — редакционный стол, карточки материалов, мета, связанное чтение, поиск поверх выпуска.
- **Фонд Шевякова / Академический** — гражданская палитра, стеклянная шапка, нумерованные секции, светлая и тёмная темы, тон фонда.

Aegis не является дочерней темой и не копирует лицензионное ядро WPShop. Это самостоятельный шаблон с собственной дизайн-системой.

## Что внутри

1. **Журнал** — featured + rail, архивы, статья с колонкой и «читать следом».
2. **Зал памяти героев** — CPT `aegis_hero`, горизонтальный портретный ритм, отдельная этика (без счётчиков популярности).
3. **Фонд инициатив** — CPT `aegis_initiative`, гражданское голосование (один голос на инициативу), заявка на модерацию.

UX 2027: fluid type, `color-mix` / oklab, grain paper, sticky glass header, dark mode, scroll-reveal, civic ballot numbers, editorial masthead.

## Установка

1. Загрузите папку `aegis` в `/wp-content/themes/` или установите архив `aegis.zip` через «Внешний вид → Темы».
2. Активируйте тему **Aegis**.
3. При первой активации тема посеет демонстрационные статьи, карточки памяти и инициативы. Это образцы композиции — замените их проверенными материалами.
4. «Настройки → Постоянные ссылки» — сохраните структуру, чтобы заработали `/memory/` и `/initiatives/`.
5. «Внешний вид → Настроить → Aegis — журнал и фонд» — тексты главной, почта, видимость секций.
6. Назначьте меню областям «Основное меню» и «Меню в подвале».

## Гибкость

- Кастомайзер: кернер, город выпуска, герой главной, тексты фонда, включение секций.
- Шаблоны страниц: «Зал памяти», «Фонд инициатив», «О фонде».
- Block editor + `theme.json`.
- Виджеты: боковая колонка и подвал.
- REST: `POST /wp-json/aegis/v1/vote`, `POST /wp-json/aegis/v1/propose`.

## Голосование

Один голос на инициативу с устройства: cookie + хеш IP/UA на 30 дней. Закрытые инициативы не принимают голоса. Заявки создаются со статусом «На рассмотрении» и требуют модерации.

Не используйте голосование для оперативной информации. При угрозе — 112.

## Память

Не публикуйте вымышленные биографии реальных людей. Демонстрационные карточки нужно заменить на согласованные с семьями и проверяемые сведения.

## Требования

- WordPress 6.4+, рекомендуется 6.8
- PHP 7.4+
- Gutenberg / block editor
