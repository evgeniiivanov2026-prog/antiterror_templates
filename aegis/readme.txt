== Description ==

Aegis собирает журнальную сетку JournalX и гражданскую систему Фонда Шевякова в самостоятельную тему для WordPress 6.7+.

* Редакционный стол: featured + rail, архивы, статья, связанное чтение
* Зал памяти героев без счётчиков популярности
* Фонд инициатив: один голос на проект, заявка на модерацию
* Светлая и тёмная темы, кастомайзер, theme.json

== Installation ==

1. Загрузите тему в /wp-content/themes/aegis/ или через «Добавить новую».
2. Активируйте тему.
3. Сохраните постоянные ссылки.
4. Настройте тексты в «Aegis — журнал и фонд».
