# GNSS.PRO

Журнал о ГЛОНАСС и глобальных навигационных спутниковых системах. Сайт собран на WordPress: редакционная тема, десять стартовых материалов, справочник систем и глоссарий.

Тема оформлена как издание, а не как универсальный блог. На главной — материал номера, номинал группировки ГЛОНАСС, рубрики и сравнение четырёх глобальных систем. В статьях — орбита, сигналы L1/L2/L3, RTK и PPP, ЭРА-ГЛОНАСС, точное земледелие, ПЗ-90.11, выбор приёмника, SBAS/СДКМ и служба времени.

Код темы распространяется по GPL v2 или новее, как того требует WordPress. Тексты журнала написаны для этого издания.

## Что публикуется

- Главная страница журнала
- Журнал со всеми материалами, рубрики и метки
- Страница «Системы» с номинальными параметрами ГЛОНАСС, GPS, Galileo, BeiDou, QZSS и NavIC
- Глоссарий
- Страницы «О журнале» и «Контакты»
- Поиск, лента и карта сайта WordPress (`/wp-sitemap.xml`)

Номинальные параметры в текстах — проектное устройство систем. Живой состав ГЛОНАСС смотрят в сводке [ИАЦ КВНО](https://glonass-iac.ru/).

## Локальный запуск без Docker

Нужны Apache, MariaDB и PHP 8.1+ с расширениями `mysqli`, `xml`, `mbstring`, `curl`, `zip`, `gd`, `intl`.

```bash
bin/setup-local.sh
```

Скрипт скачивает WordPress в `runtime/` (каталог не коммитится), ставит сайт на `http://127.0.0.1:8080`, включает тему и заливает материалы. Логин и пароль редактора записываются в `.local-credentials`.

Повторный запуск не перезаписывает уже залитую версию материалов. Новая версия сида в `GNSS_SEED_VERSION` обновляет тексты с теми же ярлыками. Статьи с другими адресами скрипт не трогает.

## Запуск в Docker

```bash
cp .env.example .env
bin/docker-init.sh
```

Перед любым общим стендом пароли в `.env` нужно заменить. Значения по умолчанию годятся только для локальной машины.

## Тема

`wp-content/themes/gnss-pro` — шаблоны, стили и справочные таблицы. Материалы лежат в `wp-content/mu-plugins`: сидер `gnss-seed.php` и тексты в `content/`. Обсуждение на сайте закрыто: поправки редакция принимает письмом на hello@gnss.pro.

Проверка структуры текстов без WordPress:

```bash
php bin/check-content.php
```

## Публикация на gnss.pro

1. Поднять WordPress на домене с HTTPS.
2. Заменить пароли базы и редактора, не использовать `.local-credentials` и значения из `.env.example`.
3. В «Настройки → Общие» указать `https://gnss.pro`.
4. Оставить постоянные ссылки в виде `/%postname%/`.
5. Включить резервное копирование базы и `wp-content`.
6. Редактировать тему в репозитории. В локальной установке правка файлов из админки отключена (`DISALLOW_FILE_EDIT`).
