# GNSS.PRO

Независимый журнал о ГЛОНАСС и спутниковой навигации на WordPress. В номере — орбитальная группировка, открытые сигналы, шкалы времени, кадры координат и граница между метровой навигацией и сантиметровой геодезией.

Сайт не связан с оператором системы. Штатные числа (24 аппарата, 64,8°, 19 100 км) описывают номинальную конфигурацию, а не сегодняшнюю сводку.

## Запуск

Нужны PHP 8.1+, MariaDB и Nginx. На Ubuntu скрипт поставит недостающие пакеты сам:

```bash
cd gnss-pro
./bin/install.sh
```

Журнал открывается на [http://127.0.0.1:8080](http://127.0.0.1:8080). Логин редактора скрипт записывает в `gnss-pro/.local-credentials` (файл не коммитится). Повторный запуск обновляет материалы и не меняет пароль.

Ядро WordPress скачивается в `public/` и в репозиторий не входит. Тема лежит в `theme/`, тексты — в `content/`.

## Как устроена редакция

- Главная — обложка номера: схема группировки, основной материал, указатель разделов.
- «Журнал» — все статьи по дате.
- Разделы: ГЛОНАСС, Созвездия, Приёмники, Точность, Применения, Стандарты.
- Глоссарий, страница о проекте и форма письма. Письмо сохраняется в кабинете как закрытая запись типа «Письма».
- Новый текст можно написать в консоли WordPress. Повторный `bin/seed.php` обновляет только материалы из `content/` и не удаляет остальные записи.

Постоянные ссылки вида `/tri-ploskosti-dvadtsat-chetyre-apparata/`, разделы — `/razdel/glonass/`.

## Публикация на gnss.pro

На сервере с тем же стеком поменяйте адрес после установки:

```bash
wp option update siteurl 'https://gnss.pro' --path=public
wp option update home 'https://gnss.pro' --path=public
```

Для боевого сайта выключите `WP_DEBUG`, смените пароль базы и редактора и поставьте сертификат. Локальный пароль базы `gnss_local_dev` годится только для этой машины.

## Шрифты

В теме лежат переменные шрифты Manrope, Unbounded и Literata (OFL). Тексты лицензий — в `theme/assets/fonts/licenses/`.
