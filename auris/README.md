# AURIS

Расширение Chrome: при наведении на ссылку, по выделенному фрагменту или по открытой странице показывает карточку с оценкой, похожа ли новость на фейк.

Оценка вероятностная. Это не замена фактчекера и не приговор редакции. Страницы сами по себе не сканируются: нужен курсор, выделение, пункт меню или кнопка в окне AURIS.

## Как устроена оценка

1. Сразу, в браузере, без сети: банк российских источников, текст ссылки, кликбейт, подмена известного бренда, короткие ссылки, HTTP.
2. Сайт из банка — официальный сайт ведомства или известная российская редакция — отмечается как хороший. Сайта нет в банке — как хороший он не отмечается. Само по себе это не штамп «фейк».
3. Если включено чтение страницы, расширение забирает заголовок, описание и основной текст статьи. В карточке виден фрагмент, по которому шла оценка.
4. Выделенный абзац длиннее 160 символов открывает ту же карточку. Правый клик даёт «AURIS: проверить эту страницу» и «AURIS: проверить выделенное». В окне расширения можно проверить вкладку или вставленный текст.
5. ИИ подключается поверх этих сигналов:
   - Алиса / YandexGPT через Yandex AI Studio: API-ключ и ID каталога, модель `aliceai-llm`;
   - встроенный Gemini Nano (Prompt API Chrome), если модель уже скачана;
   - иначе Gemini или OpenAI-совместимый endpoint с вашим ключом.

Росфинмониторинг не публикует белый список новостных сайтов. Его открытый перечень — люди и организации, связанные с экстремизмом или терроризмом. AURIS этот перечень не хранит. В банке есть официальный сайт службы `fedsfm.ru` и другие открытые российские источники.

Сатира остаётся сатирой. Короткий текст не становится фейком только из-за длины. Язык — пометка, а не запрет. Если модель спорит с сайтом из банка или с явным поддельным доменом, карточка это показывает и снижает уверенность.

В модель уходят адрес, текст ссылки, заголовок, описание, фрагмент статьи и локальный вердикт. Ключ хранится в `chrome.storage.local` и уходит только выбранному провайдеру.

## Установка

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. «Загрузить распакованное» → папка `auris`.

При первом запуске откроется инструкция: наведение, банк источников и подключение Алисы. Её можно снова открыть из окна AURIS.

Разрешение на сайты нужно, чтобы прочитать текст страницы, на которую вы навели. Локальная оценка работает и без ответа сервера. Меню страницы появляется после установки.

В окне AURIS можно выключить углублённое чтение, оставить только локальные сигналы или вставить ключ Алисы, Gemini или OpenAI. Для Алисы нужен ещё ID каталога Yandex Cloud.

## Превью карточки

Из папки `auris`:

```bash
python3 -m http.server 8756
```

Откройте `http://127.0.0.1:8756/preview/`. Наведите на заголовки слева: карточка та же, что в расширении. Справа — четыре готовых состояния.

## Проверка движка

```bash
node --test auris/tests/evaluate.test.js
```

База источников стартовая. Её можно расширять в `lib/sources.js`.

Скрипт страницы для Chrome собран в `content/bundle.js`. После правок модулей его нужно пересобрать:

```bash
npx --yes esbuild auris/content/content.js --bundle --format=iife --platform=browser --target=chrome120 --outfile=auris/content/bundle.js
```
