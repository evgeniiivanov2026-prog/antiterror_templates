# AURIS

Расширение Chrome: при наведении на ссылку показывает карточку с оценкой, похожа ли новость на фейк.

Оценка вероятностная. Это не замена фактчекера и не приговор редакции.

## Как устроена оценка

1. Сразу, в браузере, без сети: домен, текст ссылки, кликбейт, подмена известного бренда, короткие ссылки, HTTP.
2. Если включено чтение заголовка, расширение забирает только `title` и описание страницы.
3. ИИ подключается поверх этих сигналов:
   - встроенный Gemini Nano (Prompt API Chrome), если модель уже скачана;
   - иначе облако Gemini или OpenAI-совместимый endpoint с вашим ключом.

Неизвестный сайт не помечается фейком. Сатира остаётся сатирой. Государственное медиа получает метку «смешанно», а не «фейк». Если модель спорит с репутацией информагентства или с явным поддельным доменом, карточка это показывает и снижает уверенность.

В модель уходят адрес, текст ссылки, заголовок, описание и локальный вердикт. Ключ хранится в `chrome.storage.local` и уходит только выбранному провайдеру.

## Установка

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. «Загрузить распакованное» → папка `auris`.

Разрешение на сайты нужно, чтобы прочитать заголовок страницы, на которую вы навели. Локальная оценка работает и без ответа сервера.

В окне AURIS можно выключить углублённое чтение, оставить только локальные сигналы или вставить ключ Gemini / OpenAI.

## Превью карточки

Из папки `auris`:

```bash
python3 -m http.server 8756
```

Откройте `http://127.0.0.1:8756/preview/`. Наведите на заголовки слева: карточка та же, что в расширении. Справа — четыре готовых состояния.

## Проверка движка

```bash
node --test auris/tests/evaluate.test.js
```

База источников стартовая. Её можно расширять в `lib/sources.js`.

Скрипт страницы для Chrome собран в `content/bundle.js`. После правок модулей его нужно пересобрать:

```bash
npx --yes esbuild auris/content/content.js --bundle --format=iife --platform=browser --target=chrome120 --outfile=auris/content/bundle.js
```
