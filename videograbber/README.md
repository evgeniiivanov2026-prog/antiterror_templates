# videograbber

Программа берёт ссылку на видео и сохраняет один полноценный MP4: картинка и звук в одном файле, контейнер с `faststart`, кодеки H.264 и AAC. Такой файл открывается в обычном плеере и подходит для скачивания.

Если ролик уже лежит в H.264 и AAC, дорожки копируются без перекодирования. В остальных случаях videograbber приводит их к этому виду.

Скачивайте только те материалы, на сохранение которых у вас есть право.

## Что нужно

- Python 3.11 или новее
- [ffmpeg](https://ffmpeg.org/) (`ffmpeg` и `ffprobe` в `PATH`)

## Установка

```bash
pip install ./videograbber
```

Команда `videograbber` появится в окружении Python.

## Веб-версия

```bash
videograbber web
```

Страница откроется на `http://127.0.0.1:8765`. Вставьте ссылку на ролик YouTube: обычное видео, Shorts или короткую `youtu.be`. Кнопка «Найти варианты для скачивания» покажет название, автора, длительность и те качества, которые есть у этого ролика — от 1080p Full HD до 144p — и отдельно «Только аудио (MP3)». Выше 1080p страница не предлагает. Плейлист целиком не скачивается, прямой эфир тоже: нужна уже готовая запись.

Файл собирается на этом компьютере и уходит в загрузки браузера. Готовый файл хранится 20 минут. Страница одна, без внешних скриптов и шрифтов. Сервер слушает только этот компьютер. `--host` и `--port` меняют адрес. Если YouTube просит подтвердить, что запрос не от робота, передайте файл cookies Netscape: `videograbber web --cookies cookies.txt`.

## Использование

```bash
videograbber "https://example.com/watch?v=123"
```

Файл появится в текущей папке, имя берётся из названия ролика.

```bash
videograbber "https://example.com/watch?v=123" --quality 720 -o ~/Videos/clip.mp4
```

| Параметр | Назначение |
| --- | --- |
| `-o`, `--output` | Файл `.mp4` или папка |
| `--quality` | `best` (по умолчанию), `2160`, `1440`, `1080`, `720`, `480`, `360`, `240`, `144` |
| `--force` | Перезаписать уже существующий файл |
| `--cookies` | Файл cookies в формате Netscape, если сайт просит вход |
| `--quiet` | Напечатать только путь к файлу |

Код выхода: `0` — файл готов, `1` — видео не скачалось или не собралось, `2` — неверная команда, `3` — нет ffmpeg.

Ссылка на плейлист не разворачивается в пачку файлов: нужна ссылка на сам ролик. Прямой эфир не сохраняется, потому что у него нет конечного файла.

Список площадок совпадает с [yt-dlp](https://github.com/yt-dlp/yt-dlp): страница ролика или прямая ссылка на файл. Если площадка просит подтвердить, что вы не бот, экспортируйте cookies браузера в файл Netscape и передайте его через `--cookies` в командной строке.

Большой обычный файл качается несколькими соединениями. Потоки HLS и DASH качаются параллельными фрагментами. Если ролик уже лежит в H.264 и AAC с заголовком в начале, повторная сборка не запускается.
