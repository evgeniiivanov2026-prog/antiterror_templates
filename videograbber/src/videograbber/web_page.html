Скачать видео с YouTube и Rutube

Вставьте ссылку на ролик YouTube или Rutube. Появятся название, автор и качества, которые есть у этого видео: MP4 до 1080p и MP3.

youtube.com/watch?v=… · youtu.be/… · youtube.com/shorts/… · rutube.ru/video/…

Ссылка распознана

1080p — для большого экрана, 720p — для телефона. Если выбранное качество не скачалось, попробуйте качество пониже. Для музыки и лекций — MP3.

Сохранить файл

Скачивайте только то, на сохранение чего у вас есть право. Готовый файл хранится на этом компьютере около 20 минут.
