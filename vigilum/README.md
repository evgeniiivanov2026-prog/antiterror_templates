# Vigilum

Гибкий журнальный шаблон антитеррора для **WordPress 6.4+ / PHP 8.1+**.

Тема собрана из двух источников репозитория:

- **JournalX** — журнальная архитектура: главный материал, рельс соседних сюжетов, лента, карточки, связанные записи, хлебные крошки, время чтения.
- **Фонд Шевякова / Root академический** — гражданская дизайн-система: тёплая бумага, флотский navy, бургунди для действия, PT/Cormorant + Manrope, стеклянная шапка, светлая/тёмная тема, миссия и обращение.

Это **самостоятельная** гибридная тема. Родительские JournalX и Root не требуются (JournalX лицензионный, Root в архиве отсутствует).

## Что умеет

| Раздел | Как устроено |
| --- | --- |
| Журнал | Обычные записи WordPress. Главная — magazine spread + лента. |
| Память героев | CPT `vigilum_hero`, архив `/geroi/`, карточки с годами, званием, местом. |
| Фонд инициатив | CPT `vigilum_initiative`, архив `/iniciativy/`, AJAX-голосование (один голос / устройство). |
| Гибкость | Customizer (заголовки, лид, почта, тема), Gutenberg-паттерны, шорткоды, шаблон «Холст». |

UX/UI 2027: fluid type, OKLCH, `color-mix`, grain overlay, glass chrome, container queries, dark mode с системным предпочтением, scroll reveal, reading progress, 44px hit-area, `prefers-reduced-motion`.

## Установка

1. Загрузите папку `vigilum` в `/wp-content/themes/` или архив темы через **Внешний вид → Темы**.
2. Активируйте **Vigilum**.
3. Тема один раз создаст страницы «Главная», «Журнал», «О проекте», «Конфиденциальность» и меню.
4. **Настройки → Постоянные ссылки** — сохраните (ЧПУ: `/geroi/`, `/iniciativy/`).
5. **Внешний вид → Настроить → Vigilum** — заголовки, выпуск, почта.

## Наполнение

- **Записи** — материалы журнала. Для обложки выпуска назначьте миниатюру первой записи.
- **Память героев** — только проверяемые биографии. Поля: годы, звание, место, награда.
- **Фонд инициатив** — статус, автор, цель голосов. Голос пишется в мету `_vigilum_votes`.
- Не публикуйте вымышленные истории героев и оперативные данные.

## Шорткоды

```
[vigilum_heroes count="4"]
[vigilum_initiatives count="3" orderby="votes"]
```

`orderby`: `votes` или `date`.

## Голосование

REST: `POST /wp-json/vigilum/v1/vote` `{ "id": 123 }`.

Защита: cookie + HMAC IP, лимит 20 попыток/час, закрытый статус `closed` не принимает голоса. Это гражданская поддержка, не юридический референдум.

Перед запуском формы обращения укажите реальную почту, политику персональных данных и согласие. Кнопка «Обратиться» открывает `mailto:`.

## Важно

- Тема не копирует vendor JournalX и не зависит от Root.
- На сайте нет вымышленных цифр, партнёров и регистрационных сведений.
- В экстренной ситуации — 112. Редакция не заменяет спецслужбы.
