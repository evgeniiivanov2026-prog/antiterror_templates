Журнальный шаблон: материалы, память героев антитеррора и фонд инициатив с голосованием читателей.

== Описание ==

Самостоятельная тема для актуального WordPress. Журнальная подача материалов сочетается со спокойной гражданской вёрсткой: крупная антиква, тёмная и светлая темы, архив памяти и открытый фонд инициатив.

Тема не является дочерней для JournalX или Root и не требует их лицензий. Родительские пакеты в репозитории остаются как референс композиции.

== Установка ==

1. Скопируйте папку `atjournal` в `wp-content/themes/` или загрузите её архивом в «Внешний вид → Темы».
2. Активируйте «Вестник антитеррора».
3. На почти пустом сайте тема один раз создаст демонстрационный выпуск: записи, карточки памяти и инициативы. Все образцы помечены, закрыты от индексации и удаляются с панели управления.
4. Назначьте меню областям «Основное меню» и «Меню в подвале», если не подошло меню, созданное при активации.
5. В «Внешний вид → Настроить → Вестник» задайте заголовок главной и почту редакции. Пока почта пуста, кнопка письма скрыта.
6. Перед публикацией удалите образцы, добавьте политику конфиденциальности и только проверяемые сведения.

== Разделы ==

* Журнал — обычные записи. Закреплённая запись становится материалом героя на главной.
* Память — тип записи «Карточка памяти»: годы, роль, место, портрет, порядок.
* Инициативы — тип записи с направлением и состоянием голосования. Читатель отдаёт один голос и может отозвать его, пока набор открыт.
* Шорткоды для любых страниц: `[atj_journal]`, `[atj_heroes]`, `[atj_initiatives]`, `[atj_vote id="123"]`.
* Шаблон страницы «Блоковый холст» и паттерны в категории «Вестник антитеррора».

== Голосование ==

Голос гостя хранится как необратимая метка. В браузере остаётся служебная cookie `atj_vid` (HttpOnly, один год). IP-адрес не записывается. У вошедшего читателя голос связан с учётной записью. Число на странице равно числу строк в таблице `wp_atj_votes`.

Это мнение аудитории журнала, а не выборы и не решение органа власти.

== Чего на сайте нет намеренно ==

Нет формы для оперативных сообщений и доносов. Угроза жизни передаётся на номер 112. Нет вымышленных реквизитов, статистики и партнёров.

== Частые вопросы ==

= Где править главную? =
Заголовок и лид — в Настройщике. Секции собраны шаблоном `front-page.php`. Дополнительный текст можно поместить в содержимое страницы, назначенной главной.

= Как закрыть голосование? =
В карточке инициативы, блок «Голосование».

= Образцы попали в поиск? =
У них стоит `noindex`. Удаление: «Консоль → Удалить образцы» в уведомлении.
