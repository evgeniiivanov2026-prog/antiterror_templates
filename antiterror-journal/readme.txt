Журнальный шаблон антитеррора: полоса, память героев и фонд инициатив с голосованием.

== Что это ==

Самостоятельная блочная тема для WordPress 7.1. Она собрана из двух опор, которые лежат в репозитории, и не требует коммерческих родительских тем:

* Журнальная архитектура в духе JournalX: обложка выпуска, главный материал и рельс коротких, архив, материал с похожими записями, поиск.
* Гражданская дизайн-система академической темы фонда: бумага, ночной синий, бордовый сигнал, нумерованные разделы, светлая и тёмная темы, липкая шапка.

Код JournalX и родительской темы Root в эту тему не входит. JournalX — коммерческий продукт, а в архиве академической темы нет родительской Root, без которой та не запускается.

== Разделы ==

* Журнал — записи типа «Запись».
* Память — тип записи «Герой памяти»: роль, годы, место, короткая формула.
* Фонд инициатив — тип записи «Инициатива». Посетитель отдаёт один голос с браузера или аккаунта. Статус «принята» закрывает голосование.
* Полоса 112 — напоминание, что редакция не заменяет экстренные службы.

Голос — публичная поддержка, не юридический референдум. Образцы при активации помечены и вымышлены.

== Установка ==

1. Скопируйте папку `antiterror-journal` в `wp-content/themes/` или загрузите её архивом в «Внешний вид → Темы».
2. Активируйте «Рубеж».
3. Тема один раз создаст страницы «Журнал» и «О журнале», меню, четыре материала, три профиля-образца и четыре инициативы. Постоянные ссылки, если были простыми, станут `/%postname%/`.
4. Внешний вид → Редактор → Шаблоны → Главная: секции можно удалять, дублировать и менять местами. Блоки лежат в категории «Рубеж».
5. Внешний вид → Рубеж: номер выпуска, сезон, почта редакции, лид обложки.
6. Перед публикацией удалите или замените всё с пометкой «Образец» и укажите реальную почту.

== Голосование ==

Счётчик хранится в мета-поле записи. Повтор с того же браузера останавливает подписанная cookie, для вошедшего пользователя — ещё и мета профиля. Сброс счётчика: боковая панель инициативы, «Обнулить счётчик».

== Гибкость ==

* Шаблоны сайта: главная, журнал, память, инициатива, материал, поиск, 404.
* Шаблон страницы «Журнал».
* Паттерн «Главная журнала».
* Своё меню, логотип и значок сайта — штатные средства WordPress.
