Гибкий журнальный шаблон антитеррора: выпуск, память героев и фонд инициатив с голосованием.

== Description ==

Antiterror Journal — самостоятельная тема WordPress 7.1, собранная из двух исходников репозитория:

1. JournalX — журнальная композиция: мачта выпуска, главный материал, карточки, связанное чтение, поиск.
2. Root «Фонд Шевякова — Академический» — гражданская дизайн-система: тёплый бумажный фон, институциональный navy, burgundy для действия, нумерованные главы, светлая/тёмная тема.

Тема не копирует коммерческое ядро JournalX и не требует родительскую Root. Это новый гибкий шаблон с собственными CPT и REST-голосованием.

= Разделы =

* Журнал — обычные записи WordPress в bento-сетке выпуска.
* Память героев — тип записи «Герои» (`/heroes/`), карточки только по проверяемым сведениям.
* Фонд инициатив — тип записи «Инициативы» (`/initiatives/`), голосование читателей.
* Обращение — конфиденциальный mailto-канал и напоминание о 112.

= Гибкость =

Все тексты обложки, выпуска, памяти, фонда и почта настраиваются в «Внешний вид → Настроить → Журнал антитеррора».
Меню: Основное, Подвал, Память. Виджеты: боковая колонка и подвал.
Гостевое голосование можно отключить в кастомайзере.

== Installation ==

1. Загрузите папку `antiterror-journal` в `/wp-content/themes/` или установите ZIP через «Внешний вид → Темы → Добавить новую».
2. Активируйте тему «Antiterror Journal».
3. Откройте Настройки → Постоянные ссылки и сохраните, чтобы заработали `/heroes/` и `/initiatives/`.
4. Внешний вид → Настроить → Журнал антитеррора: заполните тексты выпуска.
5. Добавьте записи журнала, карточки памяти и инициативы. Не публикуйте вымышленные имена и цифры.

== Frequently Asked Questions ==

= Нужны ли JournalX или Root? =

Нет. Тема автономна. Исходные архивы оставлены в репозитории как референс композиции.

= Как устроено голосование? =

REST `/wp-json/antiterror-journal/v1/vote`. Один голос на инициативу: cookie, hash браузера и (если есть) профиль пользователя. Лимит 20 попыток в час.

= Почему нет демо-героев? =

Намеренно. Память ведётся только по проверяемым сведениям.
