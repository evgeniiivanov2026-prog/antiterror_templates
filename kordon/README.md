# Кордон

Гражданский стиль форума для **XenForo 2.2 и 2.3**. Тема — память и профилактика: бумажный фон, флотский навбар, сигнальный акцент. Это не камуфляж и не оформление государственного органа.

В комплекте два выбираемых стиля:

- **Кордон** — светлая бумага
- **Кордон · ночь** — тёмная бумага, тот же каркас

Стиль не подменяет шаблоны XenForo. Он дочерний к Default: палитра и `extra.less`. Разделы, темы и сообщения остаются штатными.

## Установка

1. Скопируйте папку `styles/kordon` в корень форума, рядом с уже существующей `styles`.
2. В админке: **Оформление → Импорт**. Загрузите `kordon/style.xml`.
3. Родительский стиль — **Default style**. Без родителя форум потеряет шаблоны.
4. Повторите импорт для `kordon/style-dark.xml`, родитель снова Default.
5. Включите оба стиля как доступные пользователям. Переключатель появится в подвале.

XenForo 2.2+ умеет импорт архива: `kordon/dist/kordon.zip` и `kordon/dist/kordon-night.zip`. Архив сам переносит файлы в `data`. Обычный XML ждёт, что `styles/kordon` уже лежит в корне форума.

После импорта откройте стиль и нажмите пересборку, если шрифты не подхватились. Пути к файлам в `extra.less` идут через `{{ asset('kordon') }}`.

## Что меняется

- Шапка с маркой, строкой выпуска и подзаголовком «память и профилактика».
- Тёмный навбар, бумажная лента разделов, тёмный подвал с напоминанием про 112.
- Категории нумеруются, непрочитанный раздел отмечен сигнальной планкой.
- Темы и сообщения набираются Source Serif 4 и Manrope. Служебные подписи — IBM Plex Mono.
- Кнопки, цитаты, метки, постраничная навигация, меню и офканвас.

Строка выпуска — это `content` у `.p-header::before`. Подзаголовок под названием — `.p-header-content::after`. Текст подвала — `.p-footer-inner::before`. Название форума в шапке берётся из настроек XenForo, рядом с ним ставится знак `styles/kordon/mark.svg`.

## Виджет «112»

HTML-виджет в боковой колонке:

```html
<div class="kordon-hotline">
  <p class="kordon-hotline-kicker">Линия доверия</p>
  <a class="kordon-hotline-number" href="tel:112">112</a>
  <p class="kordon-hotline-text">Единый номер экстренных служб. Если есть угроза, звоните сразу. Форум для этого не подходит.</p>
</div>
```

Класс можно повесить на контейнер виджета. Форум не заменяет экстренный вызов.

## Макет

`kordon/preview/` — статическая проверка сетки: список разделов, список тем, тема с ответом. Это не движок XenForo, а те же классы публичных шаблонов и тот же `extra.css`.

Из каталога репозитория:

```bash
python3 -m http.server 8765
```

Дальше откройте `/kordon/preview/index.html`. В подвале ссылки «Кордон» и «Кордон · ночь» переключают тему так, как переключатель стилей на форуме.

Тексты макета вымышлены. Не публикуйте чужие биографии и фотографии без согласия семьи. Не кладите в темы оперативные подробности: для угрозы есть 112.

## Шрифты

Manrope, Source Serif 4 и IBM Plex Mono лежат в `styles/kordon/fonts/` по лицензии SIL OFL. Тексты лицензий — рядом, в файлах `OFL-*.txt`.

## Сборка XML

После правки `kordon/extra.css`:

```bash
python3 kordon/build_style.py
python3 kordon/preview/build_pages.py
```
