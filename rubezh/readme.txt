Профессиональный журнальный шаблон антитеррора: выпуск, стена памяти героев и фонд инициатив с голосованием.

== Description ==

«Рубеж» скомпонован из двух исходных тем репозитория:

* JournalX — журнальная мозаика, карточки разного масштаба, связанные материалы, мета публикации, поиск.
* Root «Академический» — гражданская шапка, светлая/тёмная тема, миссия фонда, обращение, институциональный тон.

Тема самостоятельная (не child Root и не форк vendor JournalX). Добавлены:

* тип записей «Герои памяти» (`/pamyat/`)
* тип записей «Инициативы» (`/iniciativy/`)
* голосование REST `rubezh/v1/vote` (nonce, cookie, hash IP)
* Customizer: номер выпуска, тексты секций, почта
* UX 2027: кинематографическая обложка, fluid type, стекло-навигация, civic ballot

== Installation ==

1. Загрузите папку `rubezh` в `/wp-content/themes/`
2. Внешний вид → Темы → активируйте «Рубеж — Журнал антитеррора»
3. При первой активации тема создаст демо-материалы, если память пуста
4. Настройте меню, логотип и блок «Рубеж — журнал» в Customizer

== Privacy ==

Голос хранится как cookie `rubezh_v_{id}` и transient с хешем IP. Не публикуйте оперативные сведения и персональные данные пострадавших.
