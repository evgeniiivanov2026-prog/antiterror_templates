Гибкий журнальный шаблон об антитерроре: летопись, раздел памяти и фонд инициатив с голосованием.

== Откуда композиция ==

Тема самостоятельная. Родительский код JournalX и дочерней темы «Фонд Шевякова — Академический» не копируется.

Из журнальной темы взята логика издания: обложка выпуска, карточки разного масштаба, колонка, связанные материалы, подгрузка ленты.
Из гражданской темы взяты нумерованные разделы, спокойная бумага и ночная плашка, переключение темы, бережный тон обращения.

== Установка ==

1. Скопируйте папку `rubezh` в `wp-content/themes/` или загрузите zip темы через Внешний вид → Темы → Добавить новую.
2. Активируйте «Рубеж».
3. Если постоянные ссылки ещё не заданы, тема ставит формат «название записи». Адреса раздела памяти и инициатив: `/pamyat/` и `/iniciativy/`.
4. На чистой установке тема один раз создаёт страницы «Главная» и «Летопись», меню и демонстрационные записи.
5. Удалите записи с пометкой «Образец» и опубликуйте проверенные материалы.

== Разделы ==

* Записи — летопись. Рубрики можно переименовать.
* Память — тип записи «Карточка памяти»: имя в заголовке, годы, роль, место, текст и портрет.
* Инициативы — тип записи с регионом, автором предложения и статусом. Голос принимается только в статусе «Приём голосов».
* Главная собирается из пяти блоков. Порядок и видимость: Внешний вид → Настроить → Рубеж.
* Шаблоны страниц: «Память», «Инициативы», «Страница с колонкой».
* Шорткоды: `[rubezh_memorial count="6"]` и `[rubezh_initiatives count="6"]`.

== Голосование ==

Голос — общественная поддержка, не референдум и не поручение органу.
Вошедший пользователь голосует один раз с аккаунта. Гость — один раз с браузера, по подписанной cookie. Адрес в таблицу не пишется.
Для защиты от накрутки на час хранится обезличенный счётчик действий.
В настройщике можно оставить голос только вошедшим пользователям. Для юридически значимой процедуры этого механизма недостаточно.

== Перед публикацией ==

* Укажите почту редакции и юридическую строку в настройщике. Пока почта пуста, кнопка письма скрыта.
* Не оставляйте демонстрационные карточки памяти: они не описывают реальных людей.
* Добавьте политику конфиденциальности, если собираете комментарии или почту.
* В экстренной ситуации сайт отправляет к номеру 112 и просит не проводить самостоятельное расследование.
