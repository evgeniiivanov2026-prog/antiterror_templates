# antiterror_templates

Профессиональный WordPress-шаблон **«Рубеж»** — журнальная тема антитеррора для актуального WordPress (6.4–6.8).

Исходные темы репозитория сохранены:

- `journalx.zip` — журнальная архитектура (мозаика выпуска, карточки, связанные материалы)
- `root-akademicheskiy.zip` — гражданская система Фонда (институциональная шапка, фонд, светлая/тёмная тема)

Новый шаблон **не является child-темой Root** и **не копирует коммерческое ядро WPShop**. Это самостоятельная тема в папке [`rubezh/`](rubezh/), которая берёт ритм журнала и тон института, затем добавляет стену памяти и фонд инициатив с голосованием.

## Что внутри «Рубежа»

| Раздел | Назначение |
| --- | --- |
| Обложка выпуска | Кинематографический hero, номер журнала, лидер фонда |
| Журнал | Мозаика feature + stack + trio |
| Память героев | CPT `hero`, архив `/pamyat/` |
| Фонд инициатив | CPT `initiative`, архив `/iniciativy/`, голос без регистрации |
| Обращение | Гражданский CTA, 112, без сенсаций |

Статический предпросмотр UX (без WordPress): папка [`preview/`](preview/).

## Установка в WordPress

1. Скопируйте `rubezh/` в `wp-content/themes/rubezh`.
2. Активируйте тему «Рубеж — Журнал антитеррора».
3. При пустой «Памяти» тема создаст демо-карточки, материалы и меню.
4. Внешний вид → Настроить → **Рубеж — журнал**: номер выпуска, тексты секций, почта.
5. Замените демо-биографии героев на проверяемые сведения и согласие семей.

Подробности: [`rubezh/readme.txt`](rubezh/readme.txt).
