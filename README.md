# Вестник антитеррора

Самостоятельная тема WordPress в папке `atjournal`. Это гибкий журнальный шаблон: материалы, память героев антитеррора и фонд инициатив, за которые читатели голосуют.

В репозитории лежат два исходных пакета, из которых собрана композиция:

- `journalx.zip` — журнальная подача: герой выпуска, карточки, колонка, поиск, связанные материалы.
- `root-akademicheskiy.zip` — гражданская система «Фонда Шевякова»: ночная шапка, нумерованные секции, тёмная и светлая темы, спокойный сигнал вместо крика.

Новая тема не дочерняя к JournalX или Root и не копирует их код. Она ставится на актуальный WordPress сама, без лицензионных ключей родительских тем.

## Установка

1. Скопируйте `atjournal` в `wp-content/themes/`.
2. Активируйте тему «Вестник антитеррора».
3. На новом сайте появится демонстрационный выпуск. Карточки помечены как образцы. Уведомление в консоли удаляет их одним действием.
4. Почту редакции, заголовок и лид главной задайте в «Внешний вид → Настроить → Вестник».

Подробности, шорткоды и правила голосования — в `atjournal/readme.txt`.
