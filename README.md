# antiterror_templates

Исходники, из которых собран шаблон:

- `journalx.zip` — журнальная тема JournalX. Из неё взята редакционная архитектура: обложка выпуска, главный материал и короткая рельса, архив, страница материала, похожие записи, поиск. Код темы коммерческий и в новый шаблон не копируется.
- `root-akademicheskiy.zip` — гражданская дизайн-система дочерней темы фонда: бумага, ночной синий, бордовый сигнал, нумерованные разделы, липкая шапка, светлая и тёмная темы. Родительской темы Root в архиве нет, поэтому дочерняя сама по себе не запускается.

Готовый шаблон — самостоятельная блочная тема **«Рубеж»** для WordPress 7.1:

`antiterror-journal/`

В ней три раздела: журнал, память героев антитеррора и фонд инициатив с голосованием. Секции главной переставляются в редакторе сайта. Установка и ограничения описаны в `antiterror-journal/readme.txt`.
