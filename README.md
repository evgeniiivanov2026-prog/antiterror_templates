# antiterror_templates

Профессиональный журнальный шаблон WordPress для редакции антитеррора.

## Что в репозитории

| Путь | Роль |
| --- | --- |
| `journalx.zip` | Исходная журнальная тема: сетка выпуска, карточки, типографика |
| `root-akademicheskiy.zip` | Академическая гражданская тема фонда: navy / burgundy, главы, светлая и тёмная схемы |
| `antiterror-journal/` | Новый гибкий шаблон, собранный из обеих систем |
| `antiterror-journal.zip` | Архив для установки через «Внешний вид → Темы» |

## Antiterror Journal

Тема для **последней версии WordPress (7.1)** с UX/UI 2027: стеклянная шапка, мачта выпуска, bento-журнал, стена памяти и гражданский бюллетень голосования.

Разделы:

- **Журнал** — материалы редакции
- **Память героев** — CPT `/heroes/`
- **Фонд инициатив** — CPT `/initiatives/` с голосованием
- **Обращение** — конфиденциальный канал и 112

Тексты, номер выпуска, почта и режим голосования гостей настраиваются в кастомайзере. Вымышленных героев, цифр и партнёров тема не публикует.

Подробности: [`antiterror-journal/README.txt`](antiterror-journal/README.txt).
