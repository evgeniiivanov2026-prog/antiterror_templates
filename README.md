# Шаблоны антитеррора

В репозитории три вещи:

- `journalx.zip` — журнальная тема JournalX (WPShop). Это коммерческий родитель, его код в новую тему не переносился.
- `root-akademicheskiy.zip` — дочерняя тема Root с гражданской вёрсткой: бумага, нумерованные разделы, тёмная тема, полоса действия.
- `strazha/` — самостоятельная тема для актуального WordPress. Она берёт композицию обеих: обложку и ленту журнала, колонку, подгрузку материалов, и спокойные разделы памяти и фонда.

## Тема «Стража»

Журнал антитеррора с тремя опорами:

1. Хроника — записи, рубрики, обложка, похожие материалы.
2. Память героев — тип записи «Герой», архив `/pamyat/`.
3. Фонд инициатив — тип записи «Инициатива», архив `/iniciativy/`, один голос на человека. Это голосование, не сбор средств.

Установка: «Внешний вид → Темы → Добавить новую → Загрузить тему» и выбрать папку `strazha`, либо скопировать её в `wp-content/themes/`. После активации сохраните постоянные ссылки. Тексты главной правятся в «Внешний вид → Настроить → Стража».

Подробности для редакции — в `strazha/readme.txt`.

При непосредственной угрозе на сайте указан номер 112. Тема не принимает экстренные сообщения и не предлагает действовать самостоятельно.
