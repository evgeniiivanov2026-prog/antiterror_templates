# videograbber

`videograbber` берёт ссылку на видео и собирает из неё один файл MP4, который можно скачать и открыть в обычном плеере или в браузере.

Программа сама забирает картинку и звук, а затем приводит ролик к совместимому виду:

- контейнер MP4;
- видео H.264, кадр `yuv420p`;
- звук AAC, стерео, если исходник громче или в другом кодеке;
- сведения о ролике в начале файла, чтобы воспроизведение начиналось сразу.

Если исходник уже такой, он не перекодируется: качество остаётся прежним, файл только приводится к нормальному MP4 при необходимости.

## Что нужно

- Python 3.10 или новее
- [ffmpeg](https://ffmpeg.org/) вместе с `ffprobe` (в Ubuntu: `sudo apt install ffmpeg`)

Список сайтов совпадает с [yt-dlp](https://github.com/yt-dlp/yt-dlp). Поток с DRM (например, у части платных кинотеатров) программа не обходит. Сохраняйте только то, на что у вас есть право.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

Проверка:

```bash
videograbber --version
```

## Скачать ролик

```bash
videograbber "https://example.com/watch?v=abc"
```

Готовый файл появится в папке `downloads`, а его путь будет напечатан в терминале. То же самое можно записать явно:

```bash
videograbber grab "https://example.com/watch?v=abc" -o ~/Videos -q 720
```

Качество: `best`, `2160`, `1440`, `1080`, `720`, `480`, `360`. Если выбранной высоты нет, берётся ближайшая доступная.

Полезные ключи:

- `--json` — результат в JSON, путь к файлу удобно забирать скриптом;
- `--reencode` — всегда перекодировать в H.264/AAC;
- `--force` — перезаписать MP4 с тем же именем;
- `--playlist` — каждый ролик плейлиста отдельным MP4 (по умолчанию первые 50, меняется через `--playlist-limit`);
- `--cookies файл.txt` — cookies в формате Netscape для ролика, который открывается у вас в браузере;
- `--cookies-from-browser firefox` — взять cookies из установленного браузера.

Посмотреть ролик, не скачивая его:

```bash
videograbber info "https://example.com/watch?v=abc"
```

## Страница в браузере

```bash
videograbber serve
```

Откройте `http://127.0.0.1:8765/`, вставьте ссылку и нажмите «Собрать MP4». Когда файл будет готов, его можно посмотреть на странице и скачать. Копия остаётся в папке `downloads`.

Сервер по умолчанию слушает только этот компьютер. Остановка — `Ctrl+C`. Другая папка и порт:

```bash
videograbber serve -o ~/Videos --port 9000 --open
```
