# antiterror_templates

Стиль XenForo «Контур» для форума по тематике противодействия терроризму: каталог `xenforo/antiterror`.

Архив для скачивания и установки: `kontur-antiterror.zip`. Внутри папка `kontur-antiterror` — её копируют на сервер как `styles/antiterror`, затем импортируют `style.xml`.
