# antiterror_templates

Источники:

- `journalx.zip` — журнальная тема JournalX (WPShop).
- `root-akademicheskiy.zip` — академическая дочерняя тема Фонда Шевякова (Root).

Собранный шаблон:

- **`vigilum/`** — самостоятельная тема WordPress 6.4+ / PHP 8.1+: журнал антитеррора, память героев и фонд инициатив с голосованием. Родительские темы не нужны.

Установка: загрузите папку `vigilum` в `/wp-content/themes/` и активируйте. Подробности — в `vigilum/README.md`.
