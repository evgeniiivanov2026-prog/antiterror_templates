# antiterror_templates

Профессиональный журнальный шаблон антитеррора **Aegis** для последней версии WordPress.

Тема собрана из двух исходников этого репозитория:

| Исходник | Что взято |
| --- | --- |
| `journalx.zip` | Журнальная композиция: featured + rail, карточки, мета, связанное чтение, поиск поверх выпуска |
| `root-akademicheskiy.zip` | Гражданская система: бумага / флотский / сигнальный, стеклянная шапка, нумерованные секции, светлая и тёмная темы, тон фонда |

Aegis — самостоятельная родительская тема. Она не требует Root или JournalX и не копирует лицензионное ядро WPShop.

## Установка

1. В WordPress: **Внешний вид → Темы → Добавить новую → Загрузить тему**.
2. Загрузите `aegis.zip` или папку `aegis/`.
3. Активируйте **Aegis**.
4. Сохраните **Настройки → Постоянные ссылки**, чтобы открылись `/memory/` и `/initiatives/`.
5. Тексты главной: **Внешний вид → Настроить → Aegis — журнал и фонд**.

При первой активации тема посеет демонстрационные статьи, карточки памяти и инициативы. Это образцы композиции — замените их проверенными материалами редакции. Не публикуйте вымышленные биографии реальных людей.

## Разделы шаблона

- **Журнал** — редакционный стол, архивы, статья с колонкой.
- **Память героев** — CPT «Герои», зал имён без счётчиков популярности.
- **Фонд инициатив** — CPT «Инициативы», один гражданский голос на проект, заявка на модерацию.
- **Обращение** — конфиденциальный канал фонда. При угрозе — 112.

Статический макет главной для просмотра без WordPress: `preview/index.html`.
