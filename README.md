# Шаблоны антитеррора

Журнальная тема WordPress «Рубеж» лежит в папке `rubezh`.

Она собрана как самостоятельный шаблон: журнальная сетка (обложка выпуска, карточки, колонка, подгрузка ленты) и спокойная гражданская композиция (нумерованные разделы, бумага и ночь, бережный тон). Код тем из архивов не копируется.

В теме есть летопись, раздел памяти и фонд инициатив с голосованием. Установка описана в `rubezh/readme.txt`.
