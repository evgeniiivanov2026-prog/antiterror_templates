# Контур — стиль XenForo

Стиль для открытого форума по противодействию терроризму. Служебная шапка тёмная, чтение идёт по бумажной колонке. Латунь отмечает контур и непрочитанное, малиновый цвет оставлен для действия: ответить, отправить, сообщить.

Это не макет сайта силового ведомства и не носит его эмблему. Знак — квадрат с осью, его можно заменить своим логотипом.

Нужен XenForo 2.2 или 2.3. Родитель — стандартный стиль. Шаблоны ядра не подменяются: обновление форума не затирает вёрстку, кроме вашей копии `extra.less`.

## Установка

1. Скопируйте этот каталог на сервер форума как `styles/antiterror`. Внутри должны остаться `fonts/` и `assets/mark.svg`. Пути шрифтов в CSS считаются от корня форума: `styles/antiterror/fonts/...`. Если форум лежит в подкаталоге, так и задумано: адрес считается от `css.php`.
2. Админка → Внешний вид → Стили → Импорт. Выберите `style.xml`.
3. Родительский стиль — Default style. Импорт создаёт дочерний стиль «Контур — Антитеррор» с палитрой и шаблоном `extra.less`.
4. Включите стиль и разрешите пользователям его выбирать.

Текстовый логотип стиль рисует сам: знак и строка «Противодействие терроризму» под названием форума. Название берётся из настроек доски. Если нужен свой рисунок, загрузите логотип в свойствах стиля: тогда подпись стиля не дублируется. Для вкладки браузера подходит `assets/mark.svg`.

Если XML импортировать нельзя, откройте стиль → Шаблоны → `extra.less` и вставьте файл `extra.less` целиком. Цвета из `style.xml` тогда перенесите в свойствах стиля вручную. Файл `preview/extra.css` в форум не вставляют: это сборка только для макета.

## Что менять

В начале `extra.less`:

| Переменная | Роль |
| --- | --- |
| `@at-ink` | Шапка, подвал, шапка категории |
| `@at-paper` | Фон страницы |
| `@at-sheet` | Карточки и сообщения |
| `@at-brass` | Линии, непрочитанное, служебный акцент |
| `@at-crimson` | Основное действие и важное сообщение |
| `@at-font-path` | Каталог woff2, если шрифты лежат в другом месте |

После правки `extra.less` заново соберите XML:

```bash
python3 build_style_xml.py
```

Нужен Node.js: скрипт сам вызывает `lessc` и обновляет превью.

## Макет

`preview/index.html` и `preview/thread.html` повторяют публичные классы XenForo, чтобы стиль было видно без установленного форума. Откройте их через локальный сервер из этого каталога или прямо с диска: шрифты лежат рядом.

Тексты в макете демонстрационные. Стиль не добавляет инструкции, схемы объектов и чужие гербы.

Шрифты Manrope, Literata и IBM Plex Mono распространяются по лицензии SIL Open Font License. Тексты лицензий: `fonts/OFL-manrope.txt`, `fonts/OFL-literata.txt`, `fonts/OFL-ibm-plex.txt`.
